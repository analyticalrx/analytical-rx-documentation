Airtable Interface And Automation Report

Detailed review of Airtable interface page metadata from MCP plus automation findings visible from screenshots.

Source And Scope

Interface data in this report comes from Airtable MCP list-pages-for-base. It includes page names, page types, dashboard elements, source tables, visible fields, and aggregation configuration. No underlying record values were fetched.

Automation data in this report comes from the Airtable automation screenshot only. Airtable MCP CLI version 0.2.6 did not expose a tool for listing automation definitions, and the direct metadata endpoint check did not return automation configuration.

Before implementation, each Airtable automation should be opened in the UI and reviewed step by step for exact trigger conditions, field mappings, recipients, email bodies, scripts, and external integrations.

Implementation Notes

  • Interfaces map to role-specific dashboard routes in AnalyticalRx.
  • Dashboard elements map to saved chart/KPI definitions that query typed application tables.
  • Big-number elements become KPI cards with configured aggregation functions.
  • Chart elements become reusable chart widgets with source table, x-axis, measure, and date-bucket configuration.
  • Levels elements become record-list or drill-down tables with a controlled visible-field list.
  • Automations should become backend workflow rules, scheduled jobs, and notification templates, not frontend-only behavior.

Remaining Gaps

  1. Exact automation trigger conditions and field mappings are not available from the current MCP tool list.
  2. Email recipients, notification channels, and message templates are not visible in the screenshots.
  3. Any Airtable script actions or external integrations must be opened in the Airtable UI and documented separately.
  4. Record filters applied to individual interface elements may need validation in the Airtable UI before implementation.
  5. Record values were not fetched because the base may contain sensitive operational, staff, or health-related data.
