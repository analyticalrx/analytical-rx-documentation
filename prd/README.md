# PRD Documents

Use Markdown files for active PRD review and implementation planning. The unified Markdown PRD is the source of truth.

## Start Here

- `product-requirements-document.md` - unified implementation PRD covering Phase 1 and Phase 2 using the PRD skill structure.
- `prd-readiness-review.md` - review of whether the current PRD is clear and implementation-ready.

## Recommendation

Keep the Markdown PRD as the implementation source of truth. If a formatted client artifact is needed later, generate it from the Markdown PRD instead of maintaining a second PRD by hand.
